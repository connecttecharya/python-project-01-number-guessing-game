## What is it?

It's the classic guessing game. The computer thinks of a secret number between 1 and 100, and you try to guess it. Every time you guess, it tells you whether to go higher or lower, until you finally get it.

It's a small project, but it was a great way for me to learn the basics, and I think it's a perfect first project if you're just starting out too.

## What I learned building this

- Showing messages with `print()` and asking the player for input with `input()`
- Saving things in variables, like the secret number and the number of tries
- Letting Python pick a random number with the `random` module
- Making decisions with `if`, `elif` and `else`
- Repeating code with a `while` loop until the player wins

## Want to try it?

All you need is Python 3. No extra installs.

1. Download this repo (or clone it if you know git).
2. Open a terminal in the folder.
3. Type this and press Enter:

```
python guess.py
```

If that doesn't work on your Mac or Linux machine, try `python3 guess.py` instead.
